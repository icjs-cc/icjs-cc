## 项目

### 小程序与跨端

| 项目 | 说明 |
| --- | --- |
| [itriton-mall](https://github.com/icjs-cc/itriton-mall) | 原生微信小程序商城。用本地数据就能走通浏览、加购、下单和订单处理。 |
| [itriton-uniapp](https://github.com/icjs-cc/itriton-uniapp) | 基于 uni-app 的组件库。 |
| [itriton-warrior](https://github.com/icjs-cc/itriton-warrior) | uni-app 与微信小程序的项目基础架构。 |

### 工具

| 项目 | 说明 |
| --- | --- |
| [itriton-captcha](https://github.com/icjs-cc/itriton-captcha) | 生成滑动验证码的拼图和背景图。 |
| [itriton-sftp](https://github.com/icjs-cc/itriton-sftp) | 按配置把项目部署到服务器，支持密钥登录和压缩传输。 |
| [itriton-appicons](https://github.com/icjs-cc/itriton-appicons) | 生成 ico、icns，以及 Flutter、Tauri 需要的应用图标。[在线使用](https://appicons.netlify.app) |
| [itriton-insight](https://github.com/icjs-cc/itriton-insight) | 用自然语言检索网页，整理成结构化 JSON。 |
| [itriton-skills](https://github.com/icjs-cc/itriton-skills) | 给智能 Agent 用的实用技能。 |
| [itriton-webpack](https://github.com/icjs-cc/itriton-webpack) | webpack 相关插件。 |
